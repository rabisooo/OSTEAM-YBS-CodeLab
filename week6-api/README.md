# Team Events API

A REST API for managing events, built with Node.js, Express, Prisma ORM, and PostgreSQL.

## Features

- List all events
- Retrieve an event by ID
- Create an event
- Update an event
- Delete an event
- Persist data in PostgreSQL through Prisma

## Technology Stack

- Node.js
- Express
- Prisma ORM
- PostgreSQL

## Data Model

The database contains two models:

### User

| Field | Type | Constraints |
|---|---|---|
| `id` | Integer | Primary key, auto-increment |
| `name` | String | Required |
| `email` | String | Required, unique |

### Event

| Field | Type | Constraints |
|---|---|---|
| `id` | Integer | Primary key, auto-increment |
| `title` | String | Required |
| `date` | DateTime | Required |
| `done` | Boolean | Defaults to `false` |
| `organizerId` | Integer | Nullable foreign key to `User.id` |

A user can organize multiple events. Each event can have zero or one organizer.

See [ER_DIAGRAM.md](./ER_DIAGRAM.md) for the entity-relationship diagram.

## Requirements

- Node.js and npm
- PostgreSQL

## Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/rabisooo/OSTEAM-YBS-CodeLab.git
   cd OSTEAM-YBS-CodeLab/week6-api
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Create a `.env` file in the `week6-api` directory and add your local PostgreSQL connection string:

   ```env
   DATABASE_URL="postgresql://USER:PASSWORD@localhost:5432/DATABASE_NAME"
   ```

   Replace the placeholders with your local PostgreSQL username, password, and database name. Do not commit or share your real `.env` file.

4. Apply database migrations:

   ```bash
   npx prisma migrate dev
   ```

5. (Optional) Seed the database:

   ```bash
   node prisma/seed.js
   ```

6. Start the API:

   ```bash
   node --watch server.js
   ```

The server runs at `http://localhost:3000` unless configured otherwise.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/events` | Get all events |
| `GET` | `/api/events/:id` | Get one event by ID |
| `POST` | `/api/events` | Create an event |
| `PUT` | `/api/events/:id` | Update an event |
| `DELETE` | `/api/events/:id` | Delete an event |

### Example: Create an event

`POST /api/events`

```json
{
  "title": "Team Meeting",
  "date": "2026-12-18T10:00:00.000Z",
  "done": false,
  "organizerId": 1
}
```
